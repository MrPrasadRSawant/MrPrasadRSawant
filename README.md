## Featured Projects

### Open RAG MCP

An open-source platform for organising private documents, generating embeddings, performing semantic retrieval and securely connecting knowledge bases with AI assistants through Model Context Protocol tools.

#### Key Features

- User workspaces and document groups
- Document ingestion and chunking
- Open-source embedding models
- Semantic vector search
- Source-grounded retrieval
- ChromaDB and PostgreSQL/pgvector support
- Secure and revocable API keys
- Bearer-authenticated MCP tools
- Multi-user data isolation
- FastAPI backend and Quasar frontend

#### Technology Stack

`Python` `FastAPI` `PostgreSQL` `pgvector` `ChromaDB`  
`MCP` `Quasar` `Vue.js` `TypeScript` `Nginx` `Linux`
